プライバシーポリシー

SongSearchFromLibrary（以下「本アプリ」）が取り扱う情報について説明します。 本アプリは作者が個人で開発・運用しているツールです。現在は限定公開で、作者およびアクセスを許可された利用者のみが利用できます。

1. 要求する権限（OAuth スコープ）

本アプリが要求する Google の権限は、次の 3 つです。

スコープ何に使うか
https://www.googleapis.com/auth/youtube.readonly 利用者本人の高評価リストとプレイリストを読み取り、検索索引を作るため
openid 次回ログイン時に同じ利用者だと判別するため。Google が発行する識別子 (sub) を受け取ります
https://www.googleapis.com/auth/userinfo.email アカウントの識別と問い合わせ対応のため。メールアドレスを受け取ります

いずれも読み取り専用の権限です。本アプリは YouTube Data API v3 に対して GET リクエストのみを発行し、利用者のアカウントへの書き込み（高評価の付け外し、 プレイリストの編集、動画の投稿、再生履歴の変更）は行いません。

本アプリはパスワードを一切保存しません。ログインは Google などの 外部アカウントとの連携のみで行います。

2. 取得する情報

上記の権限を用いて、利用者本人について次の情報を読み取ります。

情報取得元用途
高く評価した動画・曲の一覧YouTube Data API v3検索対象の決定
プレイリストとその収録曲同上検索範囲の絞り込み
曲名・アーティスト名・アルバム名・動画 ID・再生時間・サムネイル URL同上検索索引の作成と結果表示
チャンネル情報（高評価プレイリストの ID 取得のため）同上上記の取得に必要
Google が発行する識別子 (sub)OpenID Connect の ID トークン再訪時に同一利用者と判別するため
メールアドレスと確認済みフラグ、表示名、プロフィール画像 URL同上アカウントの表示と問い合わせ対応

本アプリは、Gmail、連絡先、カレンダー、位置情報、支払い情報など、 上記以外の Google ユーザーデータには一切アクセスしません。

メールアドレスをアカウントの照合に使うことはありません。 別の外部サービスのアカウントを同じ利用者に紐付けるのは、本人がログイン中に 明示的に連携操作を行った場合だけです。提供元が主張するメールアドレスの一致を 根拠に自動で紐付けることは、設計上できないようにしています。

3. 情報の利用目的

取得した情報は、利用者自身が自分の楽曲を検索できるようにすることのみに使用します。 広告、プロファイリング、行動分析、機械学習モデルの訓練には使用しません。

4. 保存場所と保存期間

取得した情報は、作者が管理する Amazon Web Services のアカウント （東京リージョン ap-northeast-1）上の SQLite データベースファイルに保存されます。 第三者のデータベースサービスには保存しません。

  • 保管先の S3 バケットは公開アクセスを全面的に遮断し、保存時暗号化 (SSE-S3) と TLS 必須のポリシーを設定しています。
  • Google の更新トークンは利用者ごとに分離したディレクトリへ、 パーミッション 0600 のファイルとして保管します。公開リポジトリには含めません。
  • 検索を提供する側が読む配信用コピーからは、更新トークンとメールアドレスを 削除してから配信します。検索処理はこれらに触れません。
  • ログイン状態は署名付き Cookie で保持します。Cookie に含まれるのは利用者番号、 失効判定用の世代番号、発行時刻と有効期限だけで、氏名やメールアドレスは含みません。

アクセス権を取り消し、作者に削除を依頼すれば、保存された情報は削除されます。

5. 外部サービスへの送信

本アプリは、機能の実現のために次の外部サービスと通信します。送信する内容を明示します。

送信先送信する内容目的
Google Gemini API 曲名、チャンネル名、再生時間、カテゴリ ID などの公開メタデータ その項目が楽曲か否か（音楽以外の動画の混入）の判定。動画本体や音声、利用者の識別情報は送信しません
YouTube Music（未認証） 動画 ID 歌詞の取得。この通信に利用者の認証情報は使用しません
LRCLIB（任意・無効化可能） 曲名、アーティスト名、再生時間 YouTube Music に歌詞が無い曲の補完

これらへの送信は、いずれも設定で無効にできます。 取得した Google ユーザーデータを、広告事業者を含むいかなる第三者にも 販売・貸与・提供しません。

5-2. 歌詞の取り扱い

本アプリは歌詞を取得しますが、歌詞の本文を画面にも API の応答にも出しません。 歌詞は検索の索引を作るためだけに使い、検索結果として返すのは曲名・アーティスト名・ アルバム名・アートワーク・再生リンク、および「なぜ一致したか」の説明だけです。

この抑制はサーバー側で行っています。画面上で隠すだけでは、開発者ツールを開けば 見えてしまうためです。

6. Google API サービスのユーザーデータに関するポリシー

本アプリによる Google API から受け取った情報の利用および他者への転送は、 Google API サービスのユーザーデータに関するポリシー （限定的使用の要件を含む）を遵守します。

7. アクセス権の取り消しとデータの削除

  1. Google アカウントの「サードパーティ製のアプリとサービス」 から本アプリを削除すると、以後のアクセスは停止します。
  2. 保存済みの情報の削除は、下記の連絡先に依頼してください。 更新トークンと、当該利用者について取得したデータを削除します。

8. セキュリティ

認証トークンはサーバー上でパーミッション 0600 のファイルとして保管し、 公開リポジトリには一切含めません。Web インターフェースへのアクセスは TLS で暗号化し、共有シークレットによる認証を必須としています。

9. 子どもの利用

本アプリは 13 歳未満の子どもの利用を想定しておらず、子どもから意図的に情報を収集することはありません。
